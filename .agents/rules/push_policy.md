# Git Push Policy

When working with this repository, agents MUST NOT push changes to the remote repository (e.g., `git push`) without explicitly asking the user for permission first.

## Rules
- You may run `git commit` locally to checkpoint your work.
- You must NOT run `git push` unless the user has explicitly typed "push it", "go ahead and push", or gave clear consent to upload to the remote repository.
- If you have prepared commits and are ready to push, stop and ask the user: "Are you ready for me to push these changes to the remote?"
