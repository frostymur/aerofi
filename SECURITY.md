# Security Policy

## Supported Versions

Currently, only the latest release of `aerofi` is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.x | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately. You can reach out to the project maintainers via their GitHub profiles or any listed contact emails. We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress.

If you have a security issue or vulnerability to report, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact on users or the system.

Thank you for helping keep `aerofi` secure!
